# Brain-Cancer-Incidence-in-the-United-States-between-2013-2017
This is a mini project that explores the brain cancer incidence across different races, ages, and sex's in the United States between 2013-2017 using python and jupyter notebook.

## Installation
Simply download jupyter notebook then install and open the .ipynb file in jupyter notebook. 

## Usage
The notebook can be previewed here in Github. It has all the steps I took to clean the data and create my visualizations. It also has the link to the data I used.
